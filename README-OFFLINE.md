# 🌐 Studyia Career - Mode Offline

## 🚀 Lancement SANS CONNEXION INTERNET

### 📋 Étapes simples :

1. **Build l'application** (une seule fois) :
   ```bash
   npm run build
   ```

2. **Double-cliquez sur** `lancer-app.bat` 
   OU
   **Ouvrez** `launch-offline.html`

3. **Connectez-vous avec** :
   - 📧 Email : `admin@studyia.net`
   - 🔑 Mot de passe : `admin123`

### 🎯 Ce qui fonctionne OFFLINE :

- ✅ **Connexion** (compte admin local)
- ✅ **Dashboard** partenaire
- ✅ **Création de CV** (interface complète)
- ✅ **Navigation** entre toutes les pages
- ✅ **Toutes les animations** et interactions
- ✅ **Mode responsive** mobile/desktop

### ⚠️ Limitations offline :

- ❌ **Pas d'appels API** externes
- ❌ **Pas de sauvegarde** distante des CV
- ❌ **Pas d'IA** (OpenRouter/Gemini)
- ❌ **Pas de synchronisation** avec le backend

### 📱 Utilisation idéale :

- **Démonstrations** clients
- **Développement** frontend
- **Tests** d'interface
- **Présentations** sans internet
- **Formation** des utilisateurs
